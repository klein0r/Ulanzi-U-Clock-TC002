## Summary

Adds `pixel-pet-display`, a native FlyThings interactive pixel pet app running on the TC002.

## Features

- Supports three pets: cat, dog and rabbit
- Turning the knob switches the current pet
- Left button triggers walking
- Middle button triggers happy
- Right button short press triggers eating
- Right button long press triggers sleeping
- The feeding animation first walks the pet over to the food bowl, then makes the food disappear
