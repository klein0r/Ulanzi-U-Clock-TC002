TC002 Xiaohongshu Follower Count

These settings are only stored in Chrome on this computer. The extension reads the TC002 configuration over the local network and sends the page data to the Home Assistant instance you specify.

Home Assistant

An HTTP address must be on the local network; HTTPS addresses are supported as well. No Home Assistant login token is required.

Use the same local-only webhook ID as in the blueprint. It acts as a shared secret, so keep it private.

Device and Profile Bindings

Each TC002 is bound to one Xiaohongshu profile. Enter the TC002 device IP; the device and the computer must be able to reach each other on the same local network.

The minimum is 5 minutes, to avoid frequent requests triggering Xiaohongshu rate limiting or an account block; a longer interval is recommended where practical.
